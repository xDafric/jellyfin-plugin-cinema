Welcome to Cinema

Cinema replaces the look of Jellyfin with a streaming-service style interface: Netflix-like home page, a Spotify-like music app, its own video player and a TV mode for Android TV. Everything works with Jellyfin alone. The connections below are optional and each one unlocks extra pages.

  1. Seerr unlocks Discover, requests, the "requested" marks and the Seerr watchlist.
  2. Radarr and Sonarr unlock download progress and the release calendar.
  3. Aurral unlocks music discovery and album requests.
  4. Use Test connection under each service. A green dot at the top means it is reachable from the Jellyfin server.
  5. Save, then reload the web page (Ctrl+F5) once to see the changes.

Seerr

Jellyseerr or Overseerr. URL: the address the Jellyfin server can reach, for example http://seerr:5055 inside Docker or http://192.168.1.20:5055. API key: in Seerr open Settings, General, copy the API key. Requests are made as the signed-in Jellyfin user, so the Jellyfin accounts must be imported into Seerr first. The key never reaches the browser; the server forwards requests.

Radarr

Movie downloads. Shows the download progress on requested titles and movie release dates in the calendar. API key: Radarr, Settings, General, Security.

Sonarr

TV show downloads. Shows the download progress and upcoming episodes in the calendar. API key: Sonarr, Settings, General, Security.

Aurral

Music discovery: recommended artists, track previews and album requests. API key: Aurral, Settings, General, API access. Without Aurral the music app still plays your own library.

How hidden titles work

Give any movie or show the tag hidden (Jellyfin, edit metadata, Tags). Cinema then removes it from every row, search, grid, request list and calendar, and from the Seerr watchlist view. Nothing is deleted and the title can still be played from a direct link.

  1. Choose an unlock code below.
  2. On any device open Cinema settings, About, and tap the version number five times. Enter the code to switch on the extended mode. Hidden titles appear again on that device only.
  3. The device stays unlocked until you deactivate it in the same dialog. Unlocking again asks for the code.
  4. In extended mode the three-dot menu of a title shows whether it is hidden and lets you hide or show it.

Unlock code

Stored only as a salted hash on the server. Use at least 4 characters. Leave it empty and press Set to remove the code (nobody can then unlock the extended mode).

Loading

How the interface reaches the browser.

Load before the page rendersCinema adds its script to the web page itself. Turn off only for troubleshooting.
Better song search for music requestsLooks songs up in a public catalogue (Apple's search API) so well known songs are found by title and artist. Only the typed search words are sent, by the server, never user names or library data. Turn off to use Aurral's own search only.
